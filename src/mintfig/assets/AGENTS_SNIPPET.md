## Scientific Figures (`mintfig`)

- To explain a result to the user in a conversation, write the takeaway sentence first, then call `mint.explain(takeaway, mint.compare(...) | mint.trend(...) | mint.change(...) | mint.distribution(...) | mint.histogram(...) | mint.relate(...) | mint.share(...) | mint.matrix(...) | mint.table(...) | mint.waterfall(...) | mint.timeline(...) | mint.flow(...), source=...)` and `print(fig.save("out.png"))` (or zero-script CLI: `mintfig inspect data.csv`, `mintfig plot data.csv --kind auto --takeaway "..." --out out.png`, `mintfig edit out.png ...`, `mintfig brief f1.png f2.png --title "..." --out report.html`). Every form accepts row-shaped data (`list[dict]` or tidy DataFrames via `name=`/`value=`/`group=`/`data=`). Show uncertainty and name it (`error=` with `error_label=`, `band=` with `band_label=`, raw observations via `mint.distribution`, `mint.histogram`, or `trend(points=)`), use `log=`/`log_x=` for values spanning decades, check the takeaway against `facts`, and send right away once `summary["ship"]` is `true` (do not re-render for minor advisory warnings). For multi-figure conversations use `mint.Session` (persistent entity colours) and `mint.brief(...).save("report.html"|"report.md")`. For fast ad-hoc chat charts where soft limits should auto-adjust instead of raising, use `with mint.lenient():` / `strict=False` / `--lenient`. For chat figures read `SKILL.md` only down to "Publication Figures".
- Build publication figures with `mintfig.Plate` or `mintfig.figure`, exposing `def build() -> Plate | Figure` (or top-level `plate` / `fig`) plus optional `CAPTION` / `TAKEAWAY` / `PANEL_NOTES`.
- Validate and export every figure with: `mintfig run plot.py --journal nature --bundle out/ --json` (supports `nature`, `science`, `science_advances`, `cell`, `pnas`, `neurips`, `screen`).
- Repair `severity == "error"` items using `issues[].fix_hint`, `panels`, and `element_locations`; review clarity warnings (`color_separation`, `clarity_metadata`, `bar_baseline_nonzero`, `chartjunk_hints`, `text_on_data`).
- Enforce a **2-loop repair cap** (`<= 2` fixes), then inspect and show `out/preview.png` to the user.
- Apply Tufte discipline: favor small multiples (`mint.ghost_context`), `mint.slopegraph`, `mint.sparkline`, `mint.range_frame`, and `mint.direct_labels` over boxed legends or spaghetti plots; reserve saturated ink for focal findings and keep bar baselines at zero.
- Use perceptual colormaps (`viridis`, `magma`, `cividis`, `mintfig_navy`, `mintfig_div`), never `jet`/`rainbow`, and never use `bbox_inches="tight"`.
